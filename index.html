step‑by‑step installation

1

Python 3.7+

Make sure Python ≥3.7 is installed.
python3 --version

2

Clone / download

Get the script expendable_orca.py or clone the repo.

git clone https://github.com/Iankulani/expendable_orca.git

3

Install deps

pip install -r requirements.txt or manually:

  • cryptography
  • pynput
  • paramiko
  • discord.py / telethon / slack-sdk
  • flask, flask-socketio, scapy, etc.
4

Run

sudo python3 expendable_orca.py (admin recommended)

interactive shell

5

Bots & web

Follow the setup prompts to enable Discord, Telegram, Slack, Signal, iMessage, WhatsApp, Web Dashboard.

web: localhost:5000
